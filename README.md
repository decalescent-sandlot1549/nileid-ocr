## 📋 How to Get the Best Results

To ensure accurate extraction, follow these tips when taking photos of ID cards:

- **Use good lighting** – Avoid shadows or glare on the card surface.
- **Keep the card flat** – Do not bend or curl the card edges.
- **Fill the frame** – Make sure the entire card is visible in the photo.
- **Avoid reflections** – If using a phone, turn off the flash and avoid taking photos at an angle.
- **Use a clean background** – A plain, dark surface helps the software find the card faster.
- **Check the resolution** – Higher resolution images produce more accurate text recognition.

## 🛠️ Troubleshooting

**The software won't open**
Make sure you have downloaded the correct file for your system. If the program does not start, try right-clicking the file and selecting "Run as administrator."

**The extraction is slow**
Processing depends on the image size and your computer's speed. For faster results, use smaller images (under 5 MB) and close other programs while running nileid-ocr.

**Arabic text is not recognized correctly**
Ensure the image is not blurry or pixelated. Retake the photo with better lighting and keep the camera steady. Also, make sure the card is not partially covered by fingers or objects.

**The National ID validation fails**
Double-check that the ID number is fully visible in the image. If the number is partially cut off, the validation will fail. Retake the photo to capture the entire number.
